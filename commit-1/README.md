# Peer2Peer Learn

Learn from Peers. Teach What You Know.

First version of the Peer-to-Peer Teaching Platform website (static HTML/CSS/JS, data kept in browser localStorage).

## Run
Open `index.html` in a browser.

## Done so far
- Landing page, course catalogue with search and filters, course details
- Registration and login (demo accounts: student@demo.com / tutor@demo.com / admin@demo.com, password Demo@1234)

## Known issues (to be fixed in later commits)
- No student, tutor or admin dashboards yet
- Passwords are stored as plain text
- Weak form validation (name, email, password, Zoom link, dates)
- Layout is not responsive on mobile
- No tests, no documentation
