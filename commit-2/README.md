# Peer2Peer Learn

Learn from Peers. Teach What You Know.

## Run
Open `index.html` in a browser.

## Done so far
- Public pages, registration and login
- Student module: dashboard, enrol, mock payment + receipt, lessons and progress, classes with **Join Class** (opens the Zoom link in a new tab), assignments, messages, notifications, feedback, profile
- Tutor module: create/edit courses and lessons, schedule classes with Zoom link, create and evaluate assignments, students, reviews, earnings

## Known issues (to be fixed in later commits)
- No admin module yet
- Passwords are stored as plain text
- Name/email/password, Zoom link and past-date checks are missing
- Layout is not responsive on mobile
- No tests, no documentation
